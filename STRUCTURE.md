# Website structure

- `index.html` — homepage
- `css/` — site-wide styles and typography
- `js/` — site-wide JavaScript
- `images/site/` — banners and site-design graphics
- `images/peter/` — Peter's portraits and personal photos
- `images/teaching/` — teaching-related images
- `images/students/` — student/class images when appropriate
- `presentations/` — teaching presentations
- `videos/` — locally hosted video assets when needed
- `downloads/` — PDFs, worksheets, and downloadable resources
- `pages/` — secondary website pages

Asset filenames should be lowercase, descriptive, and use hyphens instead of spaces.
