A companion to Conditionals: present wishes, unreal ability and possibility, desired change, past regrets, and “if only.”

Synopsis

Forms of “Wish” explains how English describes a reality we want to be different. It covers wishes about the present, unreal abilities or possibilities with could, changes we want with would, regrets about the past with the past perfect, and the stronger expression if only.

Important points

  • Wish sentences usually contain two clauses, and that is optional.
  • Use wish + past tense for a present situation you want to be different.
  • Use wish + could for an unreal ability or possibility.
  • Use wish + would when you want someone or something to change.
  • Use wish + past perfect for regrets about the past.
  • If only uses the same basic constructions but is stronger and more emphatic.
