Such and So

Choose the correct intensifier before adjectives, adverbs, nouns, and noun phrases.

All levelsSlide 1 of 14
Slide 1 of 14

Synopsis

This presentation explains how so and such make descriptions stronger. Use so before an adjective or adverb, and use such before a noun or noun phrase.

The lesson covers result clauses with that, singular and plural nouns, uncountable nouns, the quantity patterns so many, so much, so few, and so little, common mistakes, and one formal alternative pattern.

Important points

  • Use so + adjective or so + adverb.
  • Use such + a/an + adjective + singular noun.
  • Use such before plural and uncountable noun phrases.
  • Use so many and so few with countable nouns.
  • Use so much and so little with uncountable nouns.
  • The pattern so + adjective + a/an + noun is correct but formal and relatively uncommon.
