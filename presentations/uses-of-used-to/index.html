Uses of “Used To”

Separate three similar-looking constructions and use each one with the correct meaning and structure.

All levelsSlide 1 of 9
Slide 1 of 9

Synopsis

This presentation separates three constructions that look similar but have different meanings: be used to, get used to, and used to + base verb.

It explains the structures that follow each form, shows how get changes with the tense, and covers the spelling of use to after did and didn’t.

Important points

  • Use be used to + noun/gerund for something already familiar or comfortable.
  • Use get used to + noun/gerund for the process of becoming familiar or comfortable.
  • The verb get changes with the tense: getting, got, gotten, or get.
  • Use used to + base verb for a past habit or situation that is no longer true.
  • After did or didn’t, write use to without a final d.
